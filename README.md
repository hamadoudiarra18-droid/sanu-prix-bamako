# Sanu Prix à Bamako — projet Android

Projet Android (Gradle, Java, sans bibliothèque externe) qui affiche votre page
`app/src/main/assets/www/index.html` en plein écran, avec l'icône Sanu Prix.

## Installer l'application
Chaque modification envoyée sur `main` construit l'APK automatiquement.
Téléchargez **sanu-prix-bamako.apk** dans la dernière version publiée
(section « Releases » du dépôt), puis ouvrez-le sur le téléphone Android.

## Modifier la page
Remplacez `app/src/main/assets/www/index.html`, puis recompilez.
